=== aside  --help
Usage: aside [options] [prompt...]
       aside [options] <command> [args...]

Run a browsing task in Aside from the terminal.

Arguments:
  prompt                      Task prompt or URL for the browser agent

Options:
  -V, --version               Print version
  --account <id>              Account selector: u0 (first profile) or
                              u0:<profile-id>
  --host <host>               Run on a session host: 'local', a remote host id,
                              or its device name
  --profile <id>              Browser profile id on the selected host (see
                              'aside host profiles')
  -m, --model <model>         Model id, or provider/model (e.g.
                              openai/gpt-5.6-sol)
  -p, --provider <provider>   Model provider name
  -s, --speed <speed>         Model speed (choices: "default", "fast")
  --effort <effort>           Thinking effort (choices: "off", "minimal", "low",
                              "medium", "high", "xhigh", "max", "ultrabrowse")
  --permission <mode>         Session permission: ask/guard (ask before other
                              folders) or full-access (choices: "ask", "guard",
                              "full-access")
  --update                    Alias for aside update
  -h, --help                  Print help

Commands:
  account                     List and switch Aside CLI accounts.
  login [options]             Sign the CLI in by confirming a code in Settings >
                              Account > Devices
  logout                      Sign the CLI out and revoke its credentials
  host                        Inspect and select session hosts (Remote Control /
                              cloud)
  memory                      Search and read Aside's memory (read-only)
  skills                      Browse Aside's site skills (Slack, Gmail, Notion,
                              Google apps, ...) usable from aside repl
  exec [options] [prompt...]  Run a browser agent session.
  repl [options] [code...]    Run Playwright-style JavaScript in Aside Browser.
  mcp [options]               Start the MCP server over stdio.
  guide [topic]               Show how to use Aside for browser tasks.
  update                      Check for updates and install the newest release.
  session                     Inspect and control browser sessions.
  settings                    Configure Aside CLI settings.

Model options:
  Defaults come from your Aside settings.
  Pass --model provider/model (e.g. --model openai/gpt-5.6-sol). Slash form overrides --provider.
  Pass --effort ultrabrowse for proactive browsing at the model's highest thinking level.
  --permission ask and --permission guard are the same (Guard). Omit for Guard.


  aside repl "const page = await openTab('https://example.com'); console.log(await page.title())"
  aside mcp
  aside update
exit=0

=== aside session --help
Usage: aside session [options] [command]

Inspect and control browser sessions.

Options:
  -h, --help                         Print help

Commands:
  list [options]                     List sessions, including unsaved sessions.
  resume [options] <id> [prompt...]  Continue an existing session.
  stop [options] <id>                Stop a running session.
  steer [options] <id> <prompt...>   Interrupt a session with a new prompt.
  queue [options] <id> <prompt...>   Queue a follow-up prompt after the current
                                     step.
  archive [options] <id>             Archive a session.
  delete [options] <id>              Delete a session.
  help [command]                     display help for command

steer interrupts the current step. queue waits and runs next.


=== aside settings --help
Usage: aside settings [options] [command]

Configure Aside CLI settings.

Options:
  -h, --help                       Print help

Commands:
  get                              Print the effective CLI settings as JSON.
  save-sessions [options] <value>  Show CLI sessions in the chat list.
  set-default-profile <id>         Set the default profile for CLI commands.
  help [command]                   display help for command

save-sessions true puts CLI runs on the browser chat list. false (default) keeps them off it.
set-default-profile u1 uses that account's first browser profile. Use u1:<profile-id> for a specific profile.
One-shot override: --account u1:<profile-id> or --profile <profile-id>.
set-default-profile default follows the current account and its first browser profile.
